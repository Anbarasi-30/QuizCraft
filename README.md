# QuizCraft

QuizCraft is a responsive quiz creation and assessment mini project built with plain HTML, CSS and JavaScript.

## Features
- Dashboard with quiz and attempt statistics
- Built-in sample quizzes for HTML, CSS, JavaScript, Python, Web Development and General Knowledge
- Create custom quizzes with four multiple-choice options and an answer key
- Timed quiz attempts with question navigation and automatic submission
- Results with score, accuracy, answer review and topic-wise performance
- Custom quiz management and saved attempt history
- Responsive light lavender/blue UI with subtle animations
- Browser persistence using `localStorage`

## Run the project
1. Extract the ZIP file.
2. Open the `QuizCraft` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. No build command, npm, backend or database is required.

## Files
- `index.html` — application structure
- `style.css` — styles, responsive layouts and animations
- `script.js` — quiz logic, rendering and browser storage

## Important limitation
This is a frontend-only educational project. Data is saved in the current browser using `localStorage`; it is not shared between devices or users. The icons and font are loaded from external CDNs, so they may fall back if you are offline.
